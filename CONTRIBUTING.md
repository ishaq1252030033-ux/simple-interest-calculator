
# Contributing Guidelines

Thank you for your interest in contributing to the
Simple Interest Calculator project!

## Contributions Welcome

All contributions, bug reports, bug fixes,
documentation improvements, enhancements, and
ideas are welcome.

## How to Contribute

1. Fork this repository.
2. Create a new branch for your changes.
3. Make your improvements or bug fixes.
4. Test your changes before submitting.
5. Commit your changes with a clear message.
6. Submit a pull request for review.

## Reporting Bugs

If you find a bug, please open a GitHub issue
describing the problem and how to reproduce it.

## Suggestions and Enhancements

Suggestions for improving the Simple Interest
Calculator are always welcome.

## Code of Conduct

All contributors should follow the guidelines
outlined in CODE_OF_CONDUCT.md.

## Thank You

Thank you for helping improve this project!
